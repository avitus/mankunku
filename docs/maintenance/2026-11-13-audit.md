## Test review and coverage

Inventoried 535 unit files, 46 integration files, 116 browser specs, six browser
diagnostics and 22 Python test files before changes. Scanned discovery settings,
assertion presence, duplicate file contents, source-text assertions, conditional
skips and expected failures, then reviewed browser audio, documentation, storage,
settings and test infrastructure in more detail. No byte-identical test files or
assertion-free application test files were found. An AST scan of 7,390 ordinary
`it`/`test` callbacks found nine groups with identical normalized bodies. Most
exercise different recordings, keys or phrase fixtures and were retained. The
duplicated F-major unlocked-key ordering case used the same fixture and call
sequence in two files; it now lives only in the demo/rotation policy suite. This is a whole-tree inventory
with targeted behavioral review, not a claim to have manually proved every
assertion necessary.

- Removed the per-page unit file-existence checks: the rendered-documentation tests already
  read and render every published Markdown page. Kept slug uniqueness,
  breadcrumbs, unknown-page behavior and bundled assistant-context checks.
- Removed the claim that equal strings on two calls prove memoization. String
  equality cannot distinguish rebuilding from caching.
- Added rendered documentation link/anchor checks. They exposed links from three
  public guides to unpublished developer pages. Those links now use repository
  sources rather than returning 404 in the app.
- Enabled deterministic native sampler ownership cases in CI. The local-sandbox
  gate was unnecessary: these tests synthesize their own buffers, fetch no sample
  bank and use OfflineAudioContext. Kept future cancellation, mid-note cancellation,
  partial-start rollback, surviving ownership and natural completion contracts.
- Removed the old raw-sampler counterexample that demanded cancellation remain
  broken. It produced silence with the installed dependency; production behavior
  tests and the positive surviving-voice case remain.
- Fixed unreachable bass/piano stem and rolling live-output cases. `CI=1` is also
  set inside the local sandbox, so their old skip disabled them everywhere allowed
  by the desktop policy. They now use deterministic audible samples and retain
  native render/continuity/loop-seam assertions.
- Moved real-CDN keyboard calibration and the full historical phrasing matrix to
  `*.diagnostic.ts`, preserving every release/seed/style assertion. They were
  already skipped in hosted CI. Explicit diagnostics make their opt-in status
  visible instead of inflating ordinary discovery with permanently skipped cases.
- Consolidated three identical TypeScript-to-browser module loaders into
  `tests/e2e/fixtures/browser-module.ts`.
